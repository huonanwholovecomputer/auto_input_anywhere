# 键盘输入助手

把一段文本自动「敲」进当前光标所在的输入框。适合往网页表单、聊天窗口、远程桌面、虚拟机等**不允许粘贴**的地方批量输入内容。

## 特点

用 Windows `SendInput` 的 **Unicode 模式**直接发送字符，完全绕过输入法：

- 不需要切换中英文，不用管当前是什么输入法状态
- 不经过选词，没有同音词 / 多音字问题
- 不使用剪贴板，不会覆盖你剪贴板里的内容，也绕开了禁用粘贴的限制
- 只依赖 Python 标准库，无需安装任何第三方包

## 环境要求

- Windows
- Python 3.7 或更高（用到 `sys.stdout.reconfigure`）
- 目标程序若以管理员身份运行，本脚本也需要用管理员身份运行（Windows 的 UIPI 限制）

## 使用

```bash
python 模拟键盘输入指定内容的脚本.py
```

运行后：

1. 脚本会在**桌面**创建 `input.txt`（已存在则不会覆盖）
2. 用任意编辑器打开它，写入你要输入的内容，`Ctrl+S` 保存
3. 回到脚本窗口输入 `y` 回车
4. 有 3 秒倒计时，**在这期间把光标点进目标输入框**
5. 脚本开始逐字模拟输入，输完打印「输入完成」

输入 `q` 退出。脚本可以反复使用：改完 `input.txt` 再输一次 `y` 即可。

## 配置

脚本开头的两个常量：

```python
KEY_DELAY = 0.04    # 每个字符之间的间隔（秒）
ENTER_DELAY = 0.05  # 换行后的等待时间
```

**目标程序丢字就把 `KEY_DELAY` 调大**，这是最常见的调整项。间隔越大越稳，但整体越慢。

## 打包成 exe

仓库里带了 PyInstaller 的 spec 文件，直接用它打包可以省去每次敲参数：

```bash
pip install pyinstaller
pyinstaller 键盘输入助手.spec
```

产物在 `dist/键盘输入助手.exe`，单文件、免安装 Python 环境。

> `*.exe` 和 `build/`、`dist/` 已在 `.gitignore` 中忽略，不会进版本库。需要分发时从 spec 重新构建即可。

## 已知问题与处理

**输进去的字少了 / 顺序乱了**
目标程序处理按键的速度跟不上。调大 `KEY_DELAY`（比如 `0.08`），再不行继续往上加。

**报错「SendInput 失败」，或干脆毫无反应**
目标程序以管理员身份运行，而脚本不是。用管理员身份重新打开终端再运行脚本。

**在代码编辑器里输入时缩进越来越深**
脚本已经针对编辑器的自动缩进做了处理：每次换行前先按 `Esc` 关掉可能吃掉回车的代码提示弹窗，换行后用 `Shift+Home` 选中编辑器自动插入的缩进，替换成源文本里的真实缩进。如果某个编辑器的行为仍然对不上，可以把这段逻辑按需调整（见 `newline_to` 函数）。

**emoji 或生僻字输不进去**
BMP 之外的字符会拆成 UTF-16 代理对发送，理论上都支持。个别程序对代理对的接收方式特殊，可能失败。

## 说明

- 脚本只会向**当前获得焦点的窗口**发送按键。启动后的 3 秒倒计时就是留给你切换窗口的。
- `input.txt` 放在桌面是为了好找，路径通过注册表读取真实桌面位置，OneDrive 重定向过的桌面也能正确识别。
